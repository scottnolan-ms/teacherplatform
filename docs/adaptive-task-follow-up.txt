## 4. Adaptive-task tooltip and scorecard framework

Reuse the evidence structure, but describe subtopic mastery rather than topic readiness.

Tooltip:
**{Student} is {mastery level} in {subtopic}. {Level explanation} {Relationship between prior evidence and task work}**

Select the relationship independently of the mastery level:
- Established before task, no answers: “Previous work had already established this level before the task began. No answers from this task have been added yet.”
- Unchanged: “The estimated level is unchanged from the start of this task.”
- Increased: “The estimate has risen from {previous level} to {level} since the task began.”
- Decreased: “The estimate has moved from {previous level} to {level} as new evidence became available.”
- Other work contributed: “The estimate includes work in this task and other relevant Mathspace activity.”
- No starting estimate: “There isn’t a reliable starting estimate to compare with. This level reflects the available Mathspace evidence.”

Do not attribute growth solely to the task unless supported.

Scorecard tiles:

**Prior evidence**
- Headline: {level} before task / Limited prior evidence / No prior evidence.
- Body: “Before this task began, {Student} was {level} in this subtopic, based on previous Mathspace work.”
- Use an appropriate alternative sentence when no reliable starting level exists.

**Task progress**
- Title: Task progress.
- Headline: “{counted questions} / {questions needed} questions counted”.
- Breakdown: “{count} before due date · {count} during extension”.
- Progress bar and percentage.
- Only show extension breakdown when applicable.
- Use Not started only when the student genuinely has not started.

For adaptive tasks, questions answered without skips count towards completion regardless of whether the answer is correct, partial or incorrect. Do not equate counted questions with correct answers.

**Subtopic mastery**
- Headline: {level}.
- Body: Personalised level explanation, followed by change since the task began when available.
